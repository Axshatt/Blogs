## How to Choose a Project

Don't try to build all 47 projects.

Choose projects that demonstrate **different technical abilities** rather than creating several projects that all demonstrate the same CRUD skills.

A strong portfolio combination could include:

- **Full-Stack:** Link Shortener + Analytics
- **Distributed Systems:** Real-Time Collaborative Notes
- **AI Engineering:** Domain-Specific RAG Application
- **LLM Engineering:** LLM Evaluation Platform
- **Cybersecurity:** Network Vulnerability Scanner
- **DevOps:** Kubernetes Autoscaling Demo

For every serious portfolio project, aim to include:

- GitHub repository
- Clean README
- Architecture diagram
- Tests
- Docker setup
- CI/CD
- Deployed demo
- Screenshots
- Technical write-up
- Documented design decisions

The goal isn't to have the **largest number of projects**.

The goal is to have projects that demonstrate that you can **design, build, deploy, test, and explain real software systems**.
