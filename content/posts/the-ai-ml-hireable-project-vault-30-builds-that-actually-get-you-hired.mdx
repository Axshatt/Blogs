Most AI/ML portfolios look identical: a Titanic classifier, an Iris predictor, and a sentiment analyzer with 87% accuracy nobody asked about. Recruiters skim past all three in about four seconds.

What actually gets attention in 2026 hiring is different: **deployed, end-to-end systems** with a documented failure case — not just a notebook with a metric at the bottom. Below are 30 project ideas, split into two vaults, each with a reference GitHub repo to study the architecture from.

> **How to use these links:** clone the repo to understand the pattern, then rebuild it with your own dataset, UI, and twist. Submitting the reference repo as your own project is instantly recognizable to anyone who's screened more than ten resumes — the goal is to learn the shape of a real system, not copy it.

## Vault 1: Core AI Engineering Builds

### 1. RAG Document Q&A Assistant
A FastAPI backend + Next.js chat UI over your own PDFs or notes. Deploy it live so it's clickable, not just cloneable.
**Reference:** [run-llama/llama_index](https://github.com/run-llama/llama_index)

### 2. Local/Offline LLM Chat App
Run a small open model locally — no API cost, and it demos without burning credits in an interview.
**Reference:** [ollama/ollama](https://github.com/ollama/ollama)

### 3. Multi-Agent Research/Travel Agent
Shows you understand tool-calling and agent loops, not just prompting a single call.
**Reference:** [Shubhamsaboo/awesome-llm-apps](https://github.com/Shubhamsaboo/awesome-llm-apps)

### 4. Browser-Automation AI Agent
An agent that fills forms, scrapes, or completes tasks from natural language. Strong "wow factor" in interviews.
**Reference:** [browser-use/browser-use](https://github.com/browser-use/browser-use)

### 5. Real-Time Computer Vision App (Gesture/Face Control)
Package your MediaPipe/OpenCV experience into a polished, deployed web demo with a slick frontend.
**Reference:** [google-ai-edge/mediapipe](https://github.com/google-ai-edge/mediapipe)

### 6. YOLO-Based Object Detection Product
Attendance system, PPE/safety detection, or a people-counting tool — frame it as a business problem, not a toy.
**Reference:** [ultralytics/ultralytics](https://github.com/ultralytics/ultralytics)

### 7. Fine-Tuned Small Language Model + Eval Suite
LoRA fine-tune on a niche dataset, with a documented before/after metric — not just "it works."
**Reference:** [huggingface/peft](https://github.com/huggingface/peft)

### 8. MLOps Pipeline (Train → Deploy → Monitor)
The #1 thing separating "notebook people" from hires: experiment tracking and a real deployment path.
**Reference:** [mlflow/mlflow](https://github.com/mlflow/mlflow)

### 9. Voice AI Assistant (STT → LLM → TTS)
A spoken assistant for a real task — customer support, study buddy. Doubles as demo content for your channel.
**Reference:** [openai/whisper](https://github.com/openai/whisper)

### 10. IoT + AI Dashboard on ESP32
Sensor data streamed from your Arduino/ESP32 hardware into a live dashboard with anomaly detection. Few AI candidates can do hardware + ML + frontend together — genuine differentiator.
**Reference:** [espressif/arduino-esp32](https://github.com/espressif/arduino-esp32)

### 11. 3D AI-Powered Product Configurator
Three.js/GSAP scene customized live by an LLM from natural language. Almost nobody in a typical AI applicant pool can ship this.
**Reference:** [pmndrs/react-three-fiber](https://github.com/pmndrs/react-three-fiber)

### 12. AI SaaS with Auth + Payments
A full product — sign-up, subscription, one real AI feature. Shows you can ship something sellable, not just a script.
**Reference:** [supabase/supabase](https://github.com/supabase/supabase)

### 13. Mini Workflow/Agent Orchestrator
A simplified visual builder chaining AI + API calls. Strong systems-design signal.
**Reference:** [n8n-io/n8n](https://github.com/n8n-io/n8n)

### 14. Resume/Job-Matching AI Tool
Scores or rewrites resumes against a job description — a strong portfolio piece and organic content for a dev-community audience.
**Reference:** [Shubhamsaboo/awesome-llm-apps](https://github.com/Shubhamsaboo/awesome-llm-apps)

### 15. Open-Source Contribution to a Popular AI Repo
A merged PR — bug fix, new agent template, doc improvement — carries more weight than another solo project because it's third-party verified.
**Reference:** [langchain-ai/langchain](https://github.com/langchain-ai/langchain)

## The Pattern Across All 30

A few things hold true across every project on this list:

- **Two or three deep, deployed projects beat ten shallow ones.** Pick a handful and go deep rather than sprinting through the whole list.
- **A live link plus a README that documents a real failure case** matters more than a leaderboard-topping accuracy number.
- **Recruiters rarely open your GitHub in detail** — your resume needs to summarize what each project proves in one line, and you need to be ready to talk through the architecture if asked.
- **Skip anything that reads as a course exercise** — Titanic, Iris, and single-purpose sentiment analyzers signal "completed a tutorial," not "can build."

If you're picking a starting point, projects #10 and #11 above lean on hardware and 3D/frontend skills that most AI applicants simply don't have — that combination is worth leading with.
